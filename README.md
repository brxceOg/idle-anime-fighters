# Idle Anime Fighters

A browser-based incremental anime fighting game built around a live 2D fighting arena. Recruit original fighters, watch them battle automatically, earn rewards, and upgrade their stats and techniques.

## Project status
Documentation and development standards are established. The playable arena prototype is the first implementation milestone.

## Design pillars
- Classic MUGEN-inspired 2D fighting-game presentation.
- Original anime martial-arts fighters and authored sprite animations.
- Visible, readable automatic combat with health, hit reactions, knockback, and special moves.
- Incremental progression through currency, fighter upgrades, and unlocks.
- Responsive browser-first interface.
