# Idle Anime Fighters

A browser-based incremental fighting game prototype. Recruit fighters, watch them automatically engage in a side-view arena, earn credits from knockouts, and improve the roster with global combat upgrades.

## Play locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## First playable slice
- Recruit three distinct fighters with different health, damage, and movement profiles.
- Fighters alternate between Azure and Crimson teams and automatically find opponents.
- Melee attacks, energy projectiles, hit reactions, knockback, health bars, knockouts, and respawns are simulated in real time.
- Knockouts award credits; global damage, health, and attack-speed upgrades affect the live roster.
- Progress is saved in browser local storage.
- Pause and 1×/2×/3× speed controls; responsive desktop/mobile layout.
